# EnciclopediaGranjera
Proyecto de Fundamentos
Enciclopedia Granjera.
Es un libro interactivo en el cuál debes de adivinar animales de granja por características físicas y datos del animal,
el cuál incluye un apartado con información de los animales para estudiarlos por aparte.
Es un proyecto universitario, por ende se publicarán los avances y resultado final por este medio.
